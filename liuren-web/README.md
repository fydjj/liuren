# 江氏小六壬排盘（网页版）

本文档沉淀当前实现的功能、排盘方式与 UI 规范，便于后续维护与扩展。

## 一、功能概览

- 支持按“日时起课”或“数字 N 起课”两种方式计算六宫：
  - 日时起课：使用公历日期时间换算出农历“日”，结合所选时辰；
  - 数字 N 起课：填写正整数 N，用 N 替代“日”，仍结合所选时辰；
- 自动计算并展示：
  - 日落宫（用于六星起点）与时落宫（身宫）；
  - 地支盘（身宫起，地支跳一取一）；
  - 六亲（按地支五行与自身地支五行生克判定，含兜底“兄弟”规则）；
  - 六神（按口诀起青龙并顺时针，颜色按六神自身五行渲染）；
  - 六星（以日落宫为木星起点顺时针排）；
- UI 采用 2×3 宫格布局：左下“大安”起，顺时针至“空亡”；
- 宫格内可视化展示：宫名、五行、地支（彩色胶囊）、六亲（加粗）、六神（按自身五行着色）、六星；身宫高亮标注；
- 右侧摘要同步列出每宫详情；
- 色板（可自定义）：木(#2e7d32)、火(#c62828)、土(#8d6e63)、金(#d4af37)、水(#1565c0)。

## 二、排盘方式（实现口径）

> 该实现遵循你提供的《排盘方式.md》的主要约束，关键口径如下：

1. 六宫顺序与落位
   - 固定顺序：大安 → 留连 → 速喜 → 赤口 → 小吉 → 空亡；
   - UI 布局（2 行 3 列）：
     - 第 2 行（底部）：[2,1] 大安｜[2,2] 空亡｜[2,3] 小吉；
     - 第 1 行（顶部）：[1,1] 留连｜[1,2] 速喜｜[1,3] 赤口；
     - SLOTS：大安[2,1]、留连[1,1]、速喜[1,2]、赤口[1,3]、小吉[2,3]、空亡[2,2]；

2. 起课：
   - 日时起课：以农历“日”与所选时辰起课；
   - 数字 N 起课：输入正整数 N，用 N 替代“日”；

3. 日落宫与时落宫：
   - dayIdx = (dayBase - 1) % 6；
   - timeIdx = (dayIdx + 时辰数字 - 1) % 6；
   - 时辰数字映射（子=1，丑=2，…，亥=12）；

4. 地支盘：
   - 从时落宫起（身宫），地支=当前时辰地支；顺时针逐宫，“上隔一取一”（每步 +2）；

5. 六亲判定：
   - 以“自身地支”的五行与各宫地支五行生克：同五行“兄弟”；我生“子孙”；生我“父母”；我克“妻财”；克我“官鬼”；
   - 兜底：若除身宫外无同五行，则自身宫顺时针找首个“土”地支宫标为“兄弟”；
   - 身宫强制“自身”；

6. 六神：
   - 起点口诀（子/午→大安；丑/未→留连；寅/申→速喜；卯/酉→赤口；辰/戌→小吉；巳/亥→空亡），顺时针青龙→朱雀→勾陈→白虎→玄武→螣蛇；
   - 六神五行：青龙木、朱雀火、勾陈土、白虎金、玄武水、螣蛇土；

7. 六星：
   - 以“日落宫”为木星起点，顺时针：木星→火星→土星→金星→水星→天空；

8. 农历换算：
   - 优先 Intl 中国农历（日级别），不可用时回退内置表（1990–2100），仅取“农历日”；

## 三、UI 规范

1. 宫格布局与高亮
   - 2×3 宫格，左下“大安”起顺时针；身宫高亮（描边 + “身宫”角标）。

2. 信息层次
   - 宫名（16px 粗体）→ 五行（fg-五行）→ 地支（zhi-pill，底色按地支五行）→ 六亲（14px 粗体）→ 六神（按六神五行上色）→ 六星。

3. 五行配色（CSS 变量）
   - --wood: #2e7d32、--fire: #c62828、--earth: #8d6e63、--metal: #d4af37、--water: #1565c0

4. 背景渐变（对应宫位五行）
   - .wx-木/火/土/水：color-mix(12%/5%)；.wx-金：color-mix(18%/8%)（更亮）。

5. 图例
   - 五行颜色值与六神/六星顺序说明。

## 五、快速上手

- 启动本地服务（推荐 8080）
  - Windows（Python 3）：
    `py -m http.server 8080 --bind 0.0.0.0 --directory "C:\\Users\\Mi\\liuren-web"`
    若无 py：`python -m http.server 8080 --bind 0.0.0.0 --directory "C:\\Users\\Mi\\liuren-web"`
  - macOS / Linux：
    `python3 -m http.server 8080 --bind 0.0.0.0`
- 访问地址
  - 本机浏览器：http://127.0.0.1:8080/
  - iPhone（同一网络）：`http://<电脑IPv4>:8080/`
  - 使用 Windows 移动热点：`http://192.168.137.1:8080/`
- 备用（Node）
  - `npx http-server -p 8080`

## 九、iPhone Safari 访问（无 Mac / 无开发者账号）

前提
- 电脑与 iPhone 在同一网络；或使用 Windows “移动热点”（iPhone 连接电脑分享的 Wi‑Fi）。

启动本地服务
- 推荐：`py -m http.server 8080 --bind 0.0.0.0 --directory "C:\\Users\\Mi\\liuren-web"`
- 备用：`python -m http.server 8080 --bind 0.0.0.0 --directory "C:\\Users\\Mi\\liuren-web"`
- 首次运行若有防火墙弹窗，请勾选“专用网络”。

在 iPhone Safari 访问
- 场景 A：Windows 移动热点（默认网关）
  - 打开：`http://192.168.137.1:8080/`
- 场景 B：接入家庭/办公 Wi‑Fi
  - 电脑运行 `ipconfig`，找到 Wi‑Fi 下的 IPv4 地址，例如 `10.220.17.114`；
  - 在 Safari 输入：`http://<IPv4>:8080/`（例如 `http://10.220.17.114:8080/`）。

常见问题
- 打开根路径 404：
  - 直接访问：`http://<IPv4>:8080/index.html`
  - `--directory` 必须指向文件夹（`C:\\Users\\Mi\\liuren-web`），不要指向 `index.html` 文件。
- 连不上：
  - 确认手机和电脑在同一网络，且不是“访客网络”或被 AP 隔离；
  - 防火墙：Windows 安全中心 → 防火墙与网络保护 → 允许应用通过防火墙 → 勾选 Python（py.exe / python.exe）的“专用”；
  - 仍不通可临时放行端口（管理员）：`netsh advfirewall firewall add rule name="Python HTTP 8080" dir=in action=allow protocol=TCP localport=8080`
- 端口占用：把 `8080` 改成 `8000/8081` 等，访问地址相应修改。
- 本机自测：电脑浏览器打开 `http://127.0.0.1:8080/` 验证服务；PowerShell 中 `Ctrl+C` 停止服务。
